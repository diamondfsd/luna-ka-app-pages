SUPPORT

技术支持

使用 Luna咔时需要帮助，或希望反馈问题与建议，请通过电子邮件联系我们。

联系支持

我们会通过电子邮件处理功能咨询、设备连接问题、故障反馈、隐私问题和其他支持请求。

diamondfsd@gmail.com

发送邮件时，请尽量附上 App 版本、设备型号、系统版本、相机型号、问题描述和相关截图，以便我们更快定位问题。

Contact support

We provide support by email for feature questions, camera connection issues, bug reports, privacy questions, and other requests.

diamondfsd@gmail.com

Please include the app version, device model, operating system version, camera model, a description of the issue, and relevant screenshots when possible.

相机连接问题

  • 确认蓝牙、无线网络和本地网络权限已按连接流程开启。
  • 相机与手机需要处于支持的连接模式，必要时重新启动相机。
  • 确认 Luna咔与相机使用兼容的连接方式，并尝试重新连接。
  • 若问题仍然存在，请记录错误提示并通过上方邮箱联系我们。

Camera connection issues

  • Enable Bluetooth, Wi-Fi, and local network access when requested by the connection flow.
  • Put the camera in its supported connection mode and restart it if needed.
  • Confirm that Luna咔 and the camera are using a compatible connection method, then try reconnecting.
  • If the issue continues, note any error message and contact us using the email address above.

功能与素材问题

  • 部分拍摄、云台、变焦和素材功能取决于所连接设备的能力。
  • 导出照片或视频前，请确认 Luna咔拥有所需的照片或存储访问权限。
  • 请勿通过邮件发送密码、私钥、API Key 或未经确认的原始数据包。

Features and media

  • Some capture, gimbal, zoom, and media features depend on the capabilities of the connected device.
  • Before exporting photos or videos, make sure Luna咔 has the required photo or storage access.
  • Do not send passwords, private keys, API keys, or raw packet captures unless requested.
