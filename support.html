SUPPORT

技术支持

安装或连接相机遇到问题时，请先完成下面的基础检查。

安装检查

  • 确认手机允许当前浏览器安装未知来源应用。
  • 下载完成后，核对文件扩展名为 .apk。
  • 如果系统提示版本冲突，请先保留原应用数据并安装更高版本。

Installation checks

  • Allow your browser to install apps from unknown sources.
  • Confirm that the downloaded file has an .apk extension.
  • If Android reports a version conflict, install a newer package without uninstalling the current app first.

连接检查

  • 打开手机蓝牙，并允许 Luna咔使用附近的设备。
  • 相机与手机需要处于支持的连接模式，必要时重新启动相机。
  • 如果局域网无法访问，请检查系统是否限制了 Luna咔的本地网络权限。

Connection checks

  • Turn on Bluetooth and allow Luna咔 to access nearby devices.
  • Put the camera in its supported connection mode and restart it if needed.
  • If the local network is unavailable, check whether the operating system is blocking Luna咔.
